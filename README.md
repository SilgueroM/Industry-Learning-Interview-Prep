# Semiconductor Hardware Interview & Skills Hub

A curated collection of real-world interview questions and comprehensive learning roadmaps for hardware engineering roles across the semiconductor industry. 

Whether you are targeting pre-silicon design and verification, post-silicon validation, or board-level systems engineering, this repository provides direct insights into what top semiconductor companies are actually asking and the practical resources needed to master those concepts.

## 📂 Repository Structure

This repository is divided into two primary directories:

*   **[`/interview_questions`](./interview_questions)**: Real interview questions, technical screens, and debugging scenarios from actual hiring rounds, organized by position.
*   **[`/skills`](./skills)**: Deep-dive learning guides, foundational roadmaps, and industry resources for core semiconductor and IC hardware disciplines.

## 🛠️ Industry Skills & Learning Resources (`/skills`)

This directory serves as a technical knowledge base for acquiring and sharpening specific semiconductor industry skills. Each subfolder corresponds to a discipline and contains curated study guides, software tool recommendations, and practical project ideas.

**Main Domains Covered:**
*   **Pre-Silicon Digital Design & Verification:** Resources for digital logic, RTL design (SystemVerilog/VHDL), UVM verification environments, formal verification, and physical design (PD).
*   **Analog & Mixed-Signal (AMS) IC Design:** Guides on transistor-level design, op-amps, ADCs/DACs, layout matching, and navigating EDA tools like Cadence Virtuoso and Spectre.
*   **Post-Silicon Validation & Test Engineering:** Techniques for silicon bring-up, debugging on the bench (oscilloscopes, logic analyzers), RF characterization, and building automated testbenches using Python or C.
*   **PCB Design & Hardware Systems:** Best practices for schematic capture, stack-up planning, high-speed routing, electromagnetic compatibility (EMC/EMI), and industry tools like Altium Designer or KiCAD.
*   **Embedded Systems:** Firmware development, hardware-software interfacing, microcontrollers, and low-level C programming for system-on-chip (SoC) environments.

If you have information for a domain that does not fall under these categories, your contribution is still welcome!

**How to use this section:**
Navigate to the folder of the skill you want to learn. Start with the `README.md` or `ROADMAP.md` in that specific folder for a structured learning path, followed by recommended textbooks, application notes, and hands-on exercises.

## 🤝 Contributing

Contributions are welcome and highly encouraged. If you have recently interviewed for an IC design, verification, or hardware role, or have discovered an exceptional learning resource, please share it to help others grow.

### How to Contribute:
1.  **Fork** the repository.
2.  **Create** a new branch (`git checkout -b feature/AddInterviewQuestions`).
3.  **Commit** your changes (`git commit -m 'Add Post-Silicon Validation interview PDF'`).
4.  **Push** to the branch (`git push origin feature/AddInterviewQuestions`).
5.  **Open** a Pull Request.

*Note: Please ensure that any shared interview questions do not violate active Non-Disclosure Agreements (NDAs). Generalize specific proprietary questions or company names where necessary.*
